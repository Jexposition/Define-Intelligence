# Priority 235: dependency-graph provenance and semantic integrity

## Purpose

The audit unit is now a coupled mathematical dependency edge, not a file or
symbol in isolation. A local theorem can be correct while the claimed result
still fails to compose if the object, domain, quantifier, limit, convention,
or premise direction changes between two declarations.

The controlling rule is:

> Never mark a relationship verified because both endpoints are verified.
> Verify the arrow.

## Corrected status of the five-row repair question

The current source record positively establishes production use of the repair

invariant; the connected radial/state-moment hierarchy feeds physical data,

That result is not the stronger proposition

\[
 \operatorname{Obs}_{\rm paper}(u_{\rm selected},p_{\rm selected},f_{\rm selected})
 =(M,I,J,S,C_p).
\]

No inspected production declaration currently closes that final selected
Cartesian/localised/periodised/summed observable arrow. This is a boundary
finding, not evidence that the internal engine is dead, optional, or false.

## Why endpoint compilation is insufficient

The selected theorem can establish endpoint consequences from a chain such as

\[
 \text{cycle invariant}\to\text{residual rates}\to\text{flat jets}
 \to\text{force extension}\to\text{blow-up consequence},
\]

without its public proposition containing a separately named observable
identity. That fact does not show that the manuscript mechanism is irrelevant.
It shows that two propositions must be audited separately:

1. the selected formal endpoint and its exact hypotheses; and
2. the claim that this endpoint is the completed construction described by the
   manuscript, including the observables and transformations used there.

The review must not infer either proposition from the other.

## Required proof-dependency model

The next audit register must represent conjunctions as hyperedges, not only
ordinary import edges. Each edge records:

* source and target declarations;
* the exact concrete object on both sides;
* domain and boundary (`positive-radius`, axis, torus, \(\mathbb R^3\),
  pre-singular, endpoint);
* equality strength (global, local, germ, almost-everywhere, or supportwise);
* premise direction (proved, caller-supplied, or merely packaged);
* finite/infinite and sum/integral/differentiation interchanges;
* the evidence tier: kernel, semantic correspondence, independent
  reconstruction, or numerical sanity check.

The principal value flow is:

\[
 \text{profile}\to\text{correction rows}\to\text{cycle state}
 \to\text{radial/state moments}\to\text{Cartesian potential}
 \to\operatorname{curl}\to\text{cutoff/localisation}
 \to\text{periodisation}\to\text{finite sums/tsum}
 \to(u,p,f)_{\rm selected}\to\text{endpoint consequences}.
\]
